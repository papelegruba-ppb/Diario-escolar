# Diario escolar

**Diario escolar es una aplicación digital de titularidad privada.**

La aplicación está diseñada como herramienta de apoyo para registrar experiencias e incidentes, expresar emociones y, cuando sea necesario, preparar un registro para compartir con una persona adulta de confianza o con el centro educativo.

## Uso de la aplicación

La aplicación publicada está destinada al uso de sus usuarios finales. Su uso no sustituye la atención de personas adultas de confianza, profesionales ni servicios de emergencia cuando sean necesarios.
